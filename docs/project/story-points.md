# Story Points

Story Points use Elder Scrolls-inspired ranks to estimate the approximate
amount of work required to complete an issue.

| Rank       | Approx. work |
| ---------- | -----------: |
| Novice     |    1–2 hours |
| Apprentice |    2–4 hours |
| Adept      |      ½–1 day |
| Expert     |     1–2 days |
| Master     |     2–3 days |

> Tasks larger than Master should be split into smaller issues.

### Timetable

**Days 1–2**  
Planning + Foundation + early Figma

**Days 3–4**  
Design + HTML/CSS foundation + API research

**Days 5–8**  
API integration + core game logic

**Days 9–10**  
Progression + UX + integration

**Days 11–12**  
Testing + bug fixing + refinement

**Day 13**  
Accessibility + performance + regression

**Day 14**  
Deployment + final documentation + demo

### Status

⬜ Not started  
🟨 In progress  
✅ Completed

### Scope

🎯 Core — Required for the finished project  
⭐ Stretch — Implement if time allows  
🧪 Research — Investigation / proof of concept
